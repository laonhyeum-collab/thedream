# 🎨 이미지 만들기 프롬프트 (ChatGPT 이미지 생성용)

그림이 없어도 앱은 이모지로 바로 동작해요. 아래 그림을 만들어 **정해진 이름 그대로** 넣으면, 다음에 앱을 열 때 이모지 대신 그 그림이 자동으로 나와요.

## 만드는 요령

1. **한 대화창에서 이어서** 만들어야 그림체가 같아져요. 먼저 아래 **[공통 스타일]**을 보내고, 그다음 그림을 하나씩 요청하세요.
2. 재료·악기·로고는 **투명 배경 PNG**, 정사각형(1024×1024)이에요.
3. 배경이 하얗게 나오면 "배경을 투명하게 다시 만들어 줘"라고 한 번 더 말해 주세요.
4. 다 만든 파일은 아래 표의 **폴더와 파일 이름** 그대로 저장해 주세요. (영어 소문자, `.png`)
5. 저에게 올려 주시면 제가 폴더에 넣고 크기·여백을 맞춰 드릴게요.

---

## [공통 스타일] — 맨 처음 한 번 보내기

```
지금부터 어린이 음악 교육 앱 「뮤직 플레이 팩토리」에 들어갈 그림을 여러 장 만들 거야. 모든 그림은 아래 스타일을 똑같이 지켜 줘.

- 귀엽고 밝은 어린이용 일러스트, 부드러운 3D 클레이(점토) 느낌의 카와이 스타일
- 실제 음식과 비슷하지만 동글동글하고 친근한 모양
- 파스텔 톤의 밝고 깨끗한 색, 은은한 하이라이트와 부드러운 그림자
- 얼굴(눈, 입)은 그리지 마
- 글자, 숫자, 로고, 워터마크는 절대 넣지 마
- 물체 하나만 화면 가운데에, 위아래·양옆에 여백을 10% 정도 남겨서
- 배경은 완전히 투명하게 (투명 배경 PNG)
- 정사각형 1024×1024

이해했으면 "준비됐어요"라고만 답해 줘.
```

```

컵 안은 완전히 비어 있어야 해 (빙수나 재료를 넣지 마).
컵이 그림의 가로 폭과 세로 높이를 거의 꽉 채우게 (위아래 여백 3% 정도).
연한 하늘색이 도는 맑은 유리, 왼쪽에 세로로 반짝이는 하이라이트.
투명 배경, 세로로 긴 그림 1024×1536. 글자 없음.
```
