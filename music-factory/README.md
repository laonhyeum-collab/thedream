# 뮤직 플레이 팩토리 🍧🎸🥁

> 내가 만든 모양이 음악이 된다!

재료를 컵에 쌓으면 디지털 밴드 음악이 되는 어린이(초등 1~6학년) 음악 창작 웹앱이에요. 태블릿 가로 화면에 맞춰 만들었고, PC와 세로 화면에서도 돼요.

## 창작 규칙

| 화면에서 하는 행동 | 음악에서의 뜻 |
|---|---|
| 재료 고르기 | 악기 고르기 (재료를 누르면 소리 미리 듣기) |
| 컵에 끌어다 놓기 | 음악 만들기 |
| 아래 → 위 | 연주 순서 (맨 아래 줄이 처음) |
| 같은 줄에 나란히 | 동시에 연주 |
| 크기: 아주 작음 · 작음 · 보통 · 큼 | ½박 · 1박 · 2박 · 4박 |

- 한 줄의 길이는 그 줄에서 **가장 긴 재료**만큼이고, 그다음 줄이 이어서 연주돼요. 빈 줄은 건너뛰어요.
- 줄마다 화음이 C → G → Am → F 순서로 바뀌어서, 어떻게 쌓아도 듣기 좋은 음악이 돼요.
- 기본: 4/4박자, 빠르기 100 (🐢60 ~ 🐇160), 1번 연주 (🔁 반복 켜기 가능)

### 빙수 재료와 악기

| 재료 | 악기 | 소리 |
|---|---|---|
| 🧊 얼음 | 드럼 | 박마다 쿵, 반 박에 칙 |
| 🫘 팥 | 베이스 기타 | 낮은 음을 길게 |
| 🍓 딸기 | 일렉트릭 기타 | 맑고 선명한 화음 |
| 🥭 망고 | 키보드 | 밝은 멜로디 한 음 |
| 🍡 떡 | 스네어 드럼 | 박마다 탁 |
| 🍫 초콜릿 | 일렉트릭 기타 | 지글지글 강한 파워 코드 |
| 🍬 젤리 | 신시사이저 | 뿅뿅 튀는 전자음 |
| 🥣 시리얼 | 심벌즈 | 차앙~ 츠츠츠 |
| 🍌 바나나 | 키보드 | 부드러운 화음 |
| 🍨 아이스크림 | 신시사이저 | 몽글몽글 마무리 + 반짝 |

악기 소리는 음원 파일 없이 브라우저의 Web Audio로 직접 만들어요. 그래서 따로 받을 파일이 없고, 여러 악기가 함께 울려도 끊기지 않아요.

## 메뉴

1. **음악 만들기**: 테마 고르기 → 빙수 만들기. 7개 테마 중 지금은 빙수가 열려 있고, 나머지는 "곧 열려요" 카드예요.
2. **나의 음악 보관함**: 저장한 작품을 듣기 / 고치기 / 지우기
3. **음악 만들기 도전**: 미션 7가지(⭐~⭐⭐⭐). 조건을 채우고 끝까지 들으면 성공이에요.
4. **악기 소리 체험**: 악기 7가지와 재료 10가지 소리를 길이(½·1·2·4박)를 바꿔 가며 들어 봐요.

### 창작 화면 조작

- **끌어다 놓기**: 재료를 컵 칸으로 끌어요. 이미 놓은 재료를 끌면 옮겨지고, 다른 재료 위에 놓으면 서로 자리를 바꿔요. 왼쪽 재료 목록으로 끌어다 놓으면 빠져요.
- **누르고 놓기** (끌기 어려운 저학년용): 재료를 한 번 누르고 컵의 빈 칸을 누르면 거기에 놓여요.
- **크기**: 컵의 재료를 누르면 오른쪽에 크기 버튼 4개가 나와요. 재료 모서리의 ↔ 손잡이를 끌어도 되고, 끌어서 바꾼 크기도 4단계 중 하나로 맞춰져요.
- **악기 고르기**: 재료 목록 위의 "🎚️ 재료마다 악기 고르기"나 고른 재료의 "🎚️ 악기 바꾸기"를 누르면, 재료마다 악기 소리 10가지 중 하나를 골라요. 누르면 바로 소리가 나고, "처음 악기" 표시로 기획서의 기본 악기를 알 수 있어요. 바꾼 재료에는 🎚️ 표시가 붙고, 고른 악기는 작품과 함께 저장돼요. "우리 밴드"와 도전 미션도 고른 악기를 따라가요.
- **재생**: ▶️ 재생 / ⏸️ 일시정지 / ⏮️ 처음부터 / ⏹️ 멈춤. 연주하는 동안 지금 연주하는 줄과 재료가 반짝이고 박자에 맞춰 튀어 올라요. "우리 밴드"의 악기 아이콘도 함께 움직여요. 다 끝나면 컵 전체가 반짝여요.
- 연주 중에는 고칠 수 없어요(안내 메시지가 나와요). 일시정지 중에 고치면 연주가 끝나고 바로 고칠 수 있어요.
- **PC 키보드**: 스페이스 = 재생/일시정지, 화살표 = 고른 재료 옮기기, `+`/`-` = 크기, Delete = 빼기
- 만들던 작품은 저장하지 않아도 기기에 임시로 남아서, 다시 열면 이어서 만들 수 있어요.

## 그림 넣기

지금은 이모지로 보여요. [IMAGE_PROMPTS.md](IMAGE_PROMPTS.md)의 프롬프트로 그림을 만들어 `assets/images/` 아래에 정해진 이름으로 넣으면, 이모지 대신 그 그림이 자동으로 나와요. 코드는 고치지 않아도 돼요.

## 내 컴퓨터에서 열어 보기

```bash
cd music-factory
python3 -m http.server 8080
```

브라우저에서 http://localhost:8080 을 열어요. (GitHub Pages처럼 파일을 그대로 올리는 곳이면 어디서든 돼요)

## 시험

```bash
npm test        # 음악 엔진·미션·저장 (Node 18+)
npm run e2e     # 진짜 브라우저로 처음부터 끝까지 (Playwright + Chromium 필요)
```

e2e 시험은 기획서의 검수 항목을 실제 브라우저에서 확인해요. 끌어다 놓기, 크기 4단계, 위치를 바꾸면 순서가 바뀌는지, 동시 연주, 실제 소리 크기 측정, 멈춘 뒤 남는 소리가 없는지, 재생 버튼을 연달아 눌러도 괜찮은지, 연주 중 잠금, 저장 후 새로고침하고 그대로 복원되는지, 초기화, 미션, 태블릿 터치 드래그, 폰 화면을 살펴봐요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `js/engine.js` | **공통 음악 엔진**: 크기→박자, 배치→연주 계획(순서·동시), 화음 진행. 화면·소리와 상관없는 순수 계산 |
| `js/audio.js` | 악기 소리 만들기(Web Audio)와 연주자(정확한 시간 예약, 일시정지, 반복, 멈춤) |
| `js/themes.js` | 테마별 재료 ↔ 악기 연결 정보. **새 테마는 여기에 재료 목록만 추가** |
| `js/missions.js` | 도전 미션과 조건 검사 |
| `js/storage.js` | 작품 저장(브라우저 로컬 저장소). 나중에 계정 저장으로 바꿀 때 이 파일만 고치면 됨 |
| `js/app.js` | 화면, 끌어다 놓기, 연주 애니메이션 |

### 새 테마 추가하기 (2차 개발)

`js/themes.js`에서 해당 테마의 `ingredients`를 채우고 `ready: true`로 바꾸면 돼요. 음악 엔진과 소리는 그대로 써요. 피자·햄버거·케이크의 재료↔악기 연결은 기획서대로 이미 적어 두었어요. 그림은 `assets/images/<테마 id>/`에 넣어요.
