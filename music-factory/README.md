# 뮤직 플레이 팩토리 🍧🎸🥁

> 내가 만든 모양이 음악이 된다!

재료를 컵에 쌓으면 디지털 밴드 음악이 되는 어린이(초등 1~6학년) 음악 창작 웹앱이에요. 태블릿 가로 화면에 맞춰 만들었고, PC와 세로 화면에서도 돼요.

## 창작 규칙

| 화면에서 하는 행동 | 음악에서의 뜻 |
|---|---|
| 재료 고르기 | 악기 고르기 (재료를 누르면 소리 미리 듣기) |
| 컵에 끌어다 놓기 | 음악 만들기 |
| 아래 → 위 | 연주 순서 (맨 아래 줄이 처음) |
| 같은 줄에 나란히 | 동시에 연주 |
| 크기: 아주 작음 · 작음 · 보통 · 큼 | ½박 · 1박 · 2박 · 4박 |

- 한 줄의 길이는 그 줄에서 **가장 긴 재료**만큼이고, 그다음 줄이 이어서 연주돼요. 빈 줄은 건너뛰어요.
- 줄마다 화음이 C → G → Am → F 순서로 바뀌어서, 어떻게 쌓아도 듣기 좋은 음악이 돼요.
- 기본: 4/4박자, 빠르기 100 (🐢60 ~ 🐇160), 1번 연주 (🔁 반복 켜기 가능)

### 빙수 재료와 악기

| 재료 | 악기 | 소리 |
|---|---|---|
| 🧊 얼음 | 드럼 | 박마다 쿵, 반 박에 칙 |
| 🫘 팥 | 베이스 기타 | 낮은 음을 길게 |
| 🍓 딸기 | 일렉트릭 기타 | 맑고 선명한 화음 |
| 🥭 망고 | 키보드 | 밝은 멜로디 한 음 |
| 🍡 떡 | 스네어 드럼 | 박마다 탁 |
| 🍫 초콜릿 | 일렉트릭 기타 | 지글지글 강한 파워 코드 |
| 🍬 젤리 | 신시사이저 | 뿅뿅 튀는 전자음 |
| 🥣 시리얼 | 심벌즈 | 차앙~ 츠츠츠 |
| 🍌 바나나 | 키보드 | 부드러운 화음 |
| 🍨 아이스크림 | 신시사이저 | 몽글몽글 마무리 + 반짝 |

악기 소리는 음원 파일 없이 브라우저의 Web Audio로 직접 만들어요. 그래서 따로 받을 파일이 없고, 여러 악기가 함께 울려도 끊기지 않아요.

### 테마마다 다른 악단

음악 엔진(순서·박자·동시 연주)은 모두 같고, 테마마다 **악단과 화음 흐름**이 달라요.

| 테마 | 악단 | 그릇 | 재료 → 악기 |
|---|---|---|---|
| 🍧 빙수 | 🎸 밴드 | 빙수컵 | 위 표 |
| 🍕 피자 | 🎻 오케스트라 (C–Am–F–G) | 피자 도우 | 도우 팀파니 · 토마토소스 첼로 · 치즈 바이올린 · 페퍼로니 트럼펫 · 버섯 호른 · 올리브 플루트 · 파인애플 하프 · 바질 트라이앵글 |
| 🍔 햄버거 | 🎷 재즈 밴드 (Dm7–G7–Cmaj7–A7) | 위아래 빵 | 빵 브러시 드럼 · 패티 콘트라베이스 · 치즈 피아노 · 양상추 비브라폰 · 토마토 색소폰 · 계란 뮤트 트럼펫 · 피클 핑거 스냅 |
| 🎂 케이크 | 🎁 오르골 악단 | 3단 케이크 | 시트 오르골 · 생크림 첼레스타 · 딸기 글로켄슈필 · 초콜릿 장식 핸드벨 · 사탕 실로폰 · 촛불 윈드차임 · 체리 장난감 피아노 |
| 🍦 아이스크림 | 🪘 타악기 팀 | 콘 | 콘 카혼 · 바닐라 봉고 · 초코 콩가 · 딸기맛 마라카스 · 스프링클 탬버린 · 웨하스 우드블록 · 민트 카우벨 |
| 🐯 동물 음악회 | 🥁 국악단 (5음: 도 레 미 솔 라) | 무대 | 호랑이 북 · 토끼 가야금 · 학 대금 · 거북이 징 · 까치 꽹과리 · 곰 거문고 · 다람쥐 장구 · 사슴 해금 |
| 🚀 우주 | 🎛️ 전자 음악단 (Am–F–C–G) | 밤하늘 | 로켓 전자 킥 · 행성 와블 베이스 · 별 아르페지오 · 외계인 레이저 · 인공위성 우주 패드 · 블랙홀 서브 드롭 · 혜성 하이햇 롤 · 달 리드 신스 |

- 국악단은 5음(궁상각치우)만 써서 우리 음악 느낌이 나고, 재즈는 재즈 화음, 우주는 단조 느낌이에요.
- 악기 고르기 창에서 **다른 악단의 악기를 빌려 올 수도** 있어요 (예: 피자 도우를 국악 장구로).
- 만들던 작품은 테마마다 따로 기억해요.

## 메뉴

1. **음악 만들기**: 테마 7개 (빙수 · 피자 · 햄버거 · 케이크 · 아이스크림 · 동물 음악회 · 우주). 테마마다 악단이 달라요.
2. **나의 음악 보관함**: 저장한 작품을 듣기 / 고치기 / 지우기
3. **음악 만들기 도전**: 미션 7가지(⭐~⭐⭐⭐). 조건을 채우고 끝까지 들으면 성공이에요.
4. **악기 소리 체험**: 악단 7개(밴드 · 오케스트라 · 재즈 · 오르골 · 타악기 · 국악 · 전자)를 골라, 악기와 재료 소리를 길이(½·1·2·4박)를 바꿔 가며 들어 봐요.
5. **노래 따라 만들기**: 이 앱을 위해 새로 지은 짧은 노래 6곡(⭐~⭐⭐⭐)을 듣고 컵에 똑같이 쌓아 연주해요.
   - 단계 3가지: 👀 **악보 보고**(재료와 박자가 보여요) → 🎸 **악기만 보고**(길이는 들어서) → 👂 **귀로만**(몇 층인지만 알려 줘요)
   - **악보는 다른 창 없이 컵 옆에** 있어요. 1층 악보는 컵 1층 옆, 2층 악보는 2층 옆처럼 같은 높이에 놓여서 보면서 바로 쌓을 수 있어요. 정답을 들을 때는 지금 연주하는 층의 악보가 반짝여요.
   - 🎧 정답 듣기, ✅ 맞는지 확인. 확인하면 컵 옆 악보 줄이 층마다 ✅(초록)/❌(빨강)으로 바뀌고, 틀린 이유("악기가 달라요 / 길이가 달라요 · 더 길게! / 아직 없어요")를 알려 줘요. ❌ 줄을 누르면 그 층의 이유가 다시 나와요.
   - 비교는 **소리** 기준이에요. 왼쪽·오른쪽 자리나 빈 층은 상관없고, 내가 바꾼 악기로 같은 소리를 내도 맞아요.
6. **단계별 도전** 🪜: 기본부터 한 단계씩 올라가요. 목표를 채우고 ▶️ 끝까지 들으면 통과, 앞 단계를 통과해야 다음 단계가 열려요. 진행 상황은 이 기기에 저장돼요.

   | 단계 | 배우는 것 | 목표 (빙수 · 밴드) |
   |---|---|---|
   | 1 🥁 쿵쿵! 박자 지키기 | 일정한 박 | 드럼 하나로만 4층 이상, 모두 같은 크기 |
   | 2 🎸 두 악기가 함께 | 소리 겹치기 | 드럼 + 베이스가 같은 층에서 함께 연주하는 층 2개 이상 |
   | 3 🎵 나만의 리듬 만들기 | 길고 짧은 소리 | 짧은 소리(½·1박)와 긴 소리(2·4박)를 섞어 3층 이상, 꼭 8박 |
   | 4 🎹 멜로디와 화음 | 화음 쌓기 | 베이스 + 멜로디(키보드·기타)를 같은 층에, 드럼이나 스네어로 박자 |
   | 5 🌟 나만의 편곡 완성 | 편곡 | 리듬·베이스·멜로디 모두, 4층·악기 4가지 이상, 맨 위층은 심벌즈나 신시사이저로 마무리 |

   - **🎲 랜덤 조합 도전** (5단계 통과 후): 반주 악기가 화음을 깔아 주고, 그 위에 다른 악단 악기를 쌓아요. 반주는 줄마다 그 줄의 화음을 그 줄 길이만큼 연주하고, 반주와 악기는 **같은 화음 흐름(조)·같은 빠르기**라서 어떻게 쌓아도 어울려요. 「🎹 반주 듣기」로 반주만 먼저 들을 수 있고, 「🎲 다른 조합」으로 바꿀 수 있어요(방금 한 조합은 다시 안 나와요). 목표: 악기 3가지 이상 · 3층 이상 · 한 층에 악기 2개.
     조합 8가지: 🎹🎸 피아노 + 밴드 · 🪕🎻 거문고 + 오케스트라(5음) · 🎁🎻 오르골 + 현악기 · 🪕🥁 가야금 + 국악 장단 · 🎹🎷 재즈 피아노 + 재즈 · 🎹🪘 피아노 + 타악기 · 🪕🚀 하프 + 우주 전자음 · 🎹🎺 피아노 + 오케스트라
   - **✍️ 가사 쓰기** (5단계 통과 후): 음악 만들기·랜덤 조합 화면에서 내 노래에 짧은 가사(80글자 · 4줄까지)를 붙이고, 작품과 함께 저장해 보관함에서도 보여요.
     **교육용 체크**(이 기기 안에서만 검사): 욕설·놀리는 말·무서운 말(한국어·영어, 띄어쓰기나 기호로 숨겨도), 개인 정보(전화번호·이메일·주소·"제 이름은"·학교 이름·몇 학년 몇 반), 인터넷 주소를 막고 친절한 안내를 보여 줘요. 가사는 어디에도 보내지 않아요(앱은 인터넷 연결을 쓰지 않아요). 저장된 가사도 열 때 다시 검사해요.

### 창작 화면 조작

- **끌어다 놓기**: 재료를 컵 칸으로 끌어요. 이미 놓은 재료를 끌면 옮겨지고, 다른 재료 위에 놓으면 서로 자리를 바꿔요. 왼쪽 재료 목록으로 끌어다 놓으면 빠져요.
- **누르고 놓기** (끌기 어려운 저학년용): 재료를 한 번 누르고 컵의 빈 칸을 누르면 거기에 놓여요.
- **크기**: 컵의 재료를 누르면 오른쪽에 크기 버튼 4개가 나와요. 재료 모서리의 ↔ 손잡이를 끌어도 되고, 끌어서 바꾼 크기도 4단계 중 하나로 맞춰져요.
- **악기 고르기**: 재료 목록 위의 "🎚️ 재료마다 악기 고르기"나 고른 재료의 "🎚️ 악기 바꾸기"를 누르면, 재료마다 악기를 골라요. 이 테마 악단의 악기가 먼저 나오고, 위쪽 악단 버튼으로 다른 악단 악기도 빌려 올 수 있어요. 누르면 바로 소리가 나고, "처음 악기" 표시로 기획서의 기본 악기를 알 수 있어요. 바꾼 재료에는 🎚️ 표시가 붙고, 고른 악기는 작품과 함께 저장돼요. "우리 밴드"와 도전 미션도 고른 악기를 따라가요.
- **재생**: ▶️ 재생 / ⏸️ 일시정지 / ⏮️ 처음부터 / ⏹️ 멈춤. 연주하는 동안 지금 연주하는 줄과 재료가 반짝이고 박자에 맞춰 튀어 올라요. "우리 밴드"의 악기 아이콘도 함께 움직여요. 다 끝나면 컵 전체가 반짝여요.
- 연주 중에는 고칠 수 없어요(안내 메시지가 나와요). 일시정지 중에 고치면 연주가 끝나고 바로 고칠 수 있어요.
- **PC 키보드**: 스페이스 = 재생/일시정지, 화살표 = 고른 재료 옮기기, `+`/`-` = 크기, Delete = 빼기
- 만들던 작품은 저장하지 않아도 기기에 임시로 남아서, 다시 열면 이어서 만들 수 있어요.

## 내 컴퓨터에서 열어 보기

```bash
cd music-factory
python3 -m http.server 8080
```

브라우저에서 http://localhost:8080 을 열어요. (GitHub Pages처럼 파일을 그대로 올리는 곳이면 어디서든 돼요)

## 시험

```bash
npm test        # 음악 엔진·미션·단계·조합·가사 체크·저장 (Node 18+)
npm run e2e     # 진짜 브라우저로 처음부터 끝까지 (Playwright + Chromium 필요)
```

e2e 시험은 기획서의 검수 항목을 실제 브라우저에서 확인해요. 끌어다 놓기, 크기 4단계, 위치를 바꾸면 순서가 바뀌는지, 동시 연주, 실제 소리 크기 측정, 멈춘 뒤 남는 소리가 없는지, 재생 버튼을 연달아 눌러도 괜찮은지, 연주 중 잠금, 저장 후 새로고침하고 그대로 복원되는지, 초기화, 미션, 태블릿 터치 드래그, 폰 화면을 살펴봐요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `js/engine.js` | **공통 음악 엔진**: 크기→박자, 배치→연주 계획(순서·동시), 화음 진행. 화면·소리와 상관없는 순수 계산 |
| `js/audio.js` | 연주자(정확한 시간 예약, 일시정지, 반복, 멈춤) |
| `js/voices.js`, `js/voices-band.js` | 악단 7개의 악기 소리 (Web Audio 로 직접 만든 소리) |
| `js/themes.js` | 악기 · 악단 · 테마별 재료 ↔ 악기 연결. **새 테마는 여기에 재료 목록만 추가** |
| `js/songs.js` | 노래 따라 만들기의 노래와 비교 |
| `js/missions.js` | 도전 미션과 조건 검사 |
| `js/levels.js` | 단계별 도전 1~5단계 목표 검사와 단계 열림 규칙 |
| `js/combos.js` | 랜덤 조합(반주 + 악단), 조합 무대, 랜덤 고르기 |
| `js/lyrics.js` | 가사 교육용 체크 (고운 말 · 개인 정보 · 길이) |
| `js/storage.js` | 작품 저장(브라우저 로컬 저장소). 나중에 계정 저장으로 바꿀 때 이 파일만 고치면 됨 |
| `js/app.js` | 화면, 끌어다 놓기, 연주 애니메이션 |

### 새 테마 추가하기

`js/themes.js`에 테마를 하나 더 적어요: 악단(`ensemble`), 재료 목록, 칸 수(`rows`/`cols`), 칸 자리(`cssShape`). 새 악단이 필요하면 `INSTRUMENTS`·`ENSEMBLES`에 악기를 적고 `js/voices.js`에 소리를 더해요. 그릇 모양은 `style.css`의 `.theme-<id>` 에 그려요. 그림은 `assets/images/<테마 id>/`에 넣어요.
