# 📱 MY APP MAKER

아이들이 **게임 앱을 직접 기획**하고, **AI와 함께 만들어**, **메타버스 앱 월드에 부스로 여는** 40분 × 4차시 프로젝트 도구입니다.

세 앱은 **폴더로 완전히 나뉘어** 있고, 서로의 코드를 가져다 쓰지 않습니다(공통 부분은 `shared/`에만). 기기에 저장하는 이름도 `myappmaker.student.*` / `teacher.*` / `world.*` 로 따로 써서, 한 기기에서 여러 앱을 열어도 섞이지 않습니다. (`npm test`가 이 규칙을 검사합니다.)

| 앱 (주소) | 누가 | 하는 일 |
|---|---|---|
| [`student/`](student/) | 학생 | 하고 싶은 게임을 말하면 주제 추천(안전 필터·배움 요소) → 기획서(15개 항목, 자동 저장) → 앱 제작·이미지 프롬프트 → 내 앱 붙여 넣고 시험 → 입점 신청 |
| [`teacher/`](teacher/) | 교사 | 제출 현황·기획서·앱 실행 확인 → 피드백, 입점 승인/수정 요청, 부스 번호 → 일괄 인쇄·백업 · 4차시 수업 흐름과 타이머 |
| [`world/`](world/) | 모두 | MY APP META WORLD: 가운데 「선생님의 앱」 + 학생 부스 12개가 있는 픽셀 섬. 내 캐릭터로 걸어 다니며 부스 체험, 좋아요, 미션·배지·공지·친구 |
| [`index.html`](index.html) | — | 세 앱으로 가는 첫 화면 (링크만 있음) |

## 계정 (우리 반 저장소가 있을 때)

- **관리자(선생님)**: 아이디·비밀번호로 교사 앱에 로그인. 첫 계정은 Code.gs 의 설치 열쇠로 만들고, 그다음부터 관리자 추가·비밀번호 변경.
- **학생**: 교사 앱 「👥 학생 계정」에서 번호 아이디(01, 02 …) + 숫자 4자리 비밀번호를 한꺼번에 만들고 로그인 카드를 인쇄.
  학생은 어느 노트북에서든 로그인하면 기획서·앱·그림이 저장소에서 이어지고, 입점 상태도 아이디를 따라가요. 한 노트북을 여러 학생이 써도 섞이지 않아요.
- 로그인은 서명된 출입증(12시간)으로 확인하고, 비밀번호를 새로 만들거나 계정을 지우면 예전 로그인은 바로 풀려요. 10번 틀리면 5분 잠금.

## 주제 추천과 안전 규칙 (`shared/recommend.js`)

학생이 좋아하는 것이나 만들고 싶은 게임을 쓰거나(🎤 말해도 됨) 「주제 추천받기」를 누르면, 28가지 관심 분야의 84개 주제 가운데 알맞은 것을 추천합니다.

| 학생이 말한 것 | 앱이 하는 일 |
|---|---|
| 이미 있는 게임·유명 캐릭터 (마인크래프트, 포켓몬 등) | 그대로 추천하지 않고, 좋아한 점(블록 쌓기, 도감 채우기 등)만 살린 나만의 주제로 바꿈 |
| 초등학생에게 알맞지 않은 폭력 (죽이기, 총, 피 등) | 그 말을 빼고 구하고·지키고·피하는 평화로운 주제로 바꿈 |
| 학교에서 만들 수 없는 내용 (도박, 성인, 약물 등) | 추천하지 않음 |
| 배움 요소 | 모든 추천 주제에 붙어 있고, 배움 요소가 없는 주제는 보여 주지 않음 |

기획서에 위와 같은 말이 들어가면 「3. 프롬프트」에서 고칠 항목을 알려 주고, 고칠 때까지 프롬프트 복사가 막힙니다. 교사 앱에도 「확인 필요」로 표시됩니다.

## 게임을 알맞은 크기로 만드는 규칙

| 규칙 | 앱에서 어떻게 지키나요 |
|---|---|
| 난이도는 두 단계 | 🌱 쉬움(화면 3개·규칙 1~2개) / 🌿 보통(화면 4개·게임 요소 2~3개)만 고를 수 있음 |
| 규칙·기능은 조금만 | 기능·게임 요소는 3개까지만 골라지고, 규칙 칸은 글자 수가 정해져 있음. AI에게 "더 늘리지 마"라고 요청 |
| 게임은 한 판(1단계)만 | 레벨·스테이지 선택지가 없고, AI에게 "한 판이 끝나면 결과 화면"으로 만들라고 요청 |
| 초등 교과와 연결 | 모든 추천 주제에 교과·학년군(2022 개정 교육과정, 예: 과학 3~4학년)이 붙어 있고, 기획서 4번 「배울 내용」이 꼭 쓰기 항목. AI에게 배울 내용을 게임 규칙 안에 넣으라고 요청 |
| 개인정보 쓰지 않기 | 개발자는 별명만, 학년·반 칸 없음. 전화번호·이메일·주소·학교 이름·생일 등을 쓰면 프롬프트 복사와 제출이 막힘. 진짜 이름처럼 보이는 별명은 알려 줌 |
| 그림은 앱 월드 느낌으로 | 이미지 프롬프트의 그림체가 앱 월드와 같은 파스텔 2D로 정해져 있음 |

> 교과 연계는 교과·학년군 수준으로 붙어 있습니다. 성취기준 번호까지 맞추려면 선생님이 확인해 주세요.

## 내 그림 넣기 (학생 앱 「4. 내 앱」)

그림은 앱 코드와 따로 만듭니다. 앱 코드를 만드는 AI는 그림 파일을 만들지 않기 때문입니다.

1. 그림 자리(배경 · 주인공 · 아이콘 최대 3개)마다 **📋 프롬프트**를 복사해 이미지 AI에 넣고, 그림을 기기에 저장합니다.
2. **📷 그림 올리기**로 저장한 그림을 고르면 앱이 알아서 다듬습니다.
   - 배경: 16:9로 잘라 960×540 안으로 줄입니다.
   - 주인공·아이콘: 가장자리에 이어진 **하얀 배경을 투명하게 지우고**(그림 안쪽 흰색은 그대로), 정사각형으로 줄입니다.
   - 그림은 이 브라우저 안에서만 바꾸고, 밖으로 보내지 않습니다.
3. 앱 제작 프롬프트가 AI에게 `const IMAGES = { background, hero, icon1… }` 그림 자리를 만들라고 요청해 두었습니다. 올린 그림이 그 자리에 들어가 바로 실행됩니다. 그림 자리가 없으면 「고쳐 줘」 프롬프트를 만들어 줍니다.
4. 앱 코드와 그림은 따로 저장합니다. 그래서 AI에게 코드를 다시 받아 붙여 넣어도 그림은 그대로 남고, 실행·제출할 때 합쳐집니다. 앱 크기는 500KB까지입니다.

## 메타버스 앱 월드 (MY APP META WORLD)

- **구성:** 가운데 「🎓 선생님의 앱」 건물 1개, 학생 부스 12개(01~12), 별 분수 광장, 입구 아치
- **메뉴:** 위쪽에 🏠 홈 · 🗺️ 맵(전체 보기) · ⭐ 내 앱 · 👥 친구 · 🙂 나의 공간(캐릭터 꾸미기), 왼쪽에 🧭 탐험 · ✅ 미션 · 🏅 배지 · 📢 공지
- **입장:** 우리 반 저장소가 있으면 **아이디·비밀번호로 로그인**하고 들어가요(「로그인 없이 둘러보기」도 있어요). 별명과 캐릭터는 들어간 뒤 오른쪽 위 **⚙️ 설정**에서 정하고, 아이디마다 이 기기에 따로 저장돼요. 처음 로그인하면 학생 앱에서 만든 캐릭터·별명으로 시작해요.
- **⚙️ 설정 창:** 내 계정(로그인한 아이디) · 별명(진짜 이름·연락처 안내) · 내 캐릭터 · 내 기록 · 움직이는 법 · 로그아웃
- **캐릭터:** 머리가 큰 2등신 픽셀 캐릭터. 성별(남자아이·여자아이: 반바지/치마·속눈썹)·피부·머리 모양·머리 색·윗옷·하의 색·소품을 골라요. 학생 앱 「5. 입점」에서 만든 캐릭터가 자기 부스 앞에 서 있어요
- **길 따라 걷기:** 지도 그림에서 크림색 돌길을 찾아(`world/walkmask.js`) 캐릭터가 길 위로만 걸어요. 화면을 누르면 길을 따라 돌아가는 경로를 찾아 점선으로 보여 줘요. 바다·강·연못·계곡 물은 절대 건너지 않아요(떨어진 길은 다리·땅으로 돌아 잇고, 비스듬히 모서리를 잘라 물을 스치지도 않아요). 길을 찾기 어려운 그림(직접 올린 지도 등)은 물만 빼고 어디든 걸어요
- **그림:**
  - 그림을 올리지 않으면 앱이 직접 그린 픽셀 섬으로 열려요.
  - **권장:** 교사 앱 「🏝️ 월드 꾸미기」에서 건물까지 다 그린 지도 그림을 올리고, 건물 문 자리를 눌러 찍어요(선생님 건물·시작 자리·부스 12). 그러면 그 그림이 그대로 월드가 되고, 앱은 이름표·캐릭터·들어가기만 얹어요.
- **학교 이름:** 교사가 정하면 월드 제목과 입구에 나와요(지도 그림 프롬프트에도 들어가요).
- **그림 프롬프트 문서:** [`docs/월드_이미지_프롬프트.docx`](docs/월드_이미지_프롬프트.docx) (`npm run prompts-doc`, 학교 이름을 넣으려면 `SCHOOL=해솔초등학교 npm run prompts-doc`)

## 흐름

```
학생 앱 ──(선생님께 보내기)──▶ 우리 반 저장소 (구글 시트+드라이브) ◀── 교사 앱 (승인·부스)
   │                                   │
   └─(저장소가 없으면) 제출 파일 ──▶ 교사 앱 ──▶ 메타버스 파일 ──▶ 앱 월드
                                       ▼
                               앱 월드 (승인한 앱만 부스로)
```

- 학생 앱(AI가 만든 HTML)은 앱 월드·교사 앱 안에서 **격리된 상자(iframe sandbox)**로 실행되어 이 사이트의 저장소·다른 학생 데이터에 접근할 수 없습니다.
- 저장소가 연결되지 않으면 앱 월드는 **체험용 샘플 부스 3개**(과일 바구니, 동물 짝꿍 카드, 무궁화 꽃이 피었습니다)로 열립니다.

## 내 컴퓨터에서

```bash
cd myappmaker
npm start          # 사이트 + 가짜 우리 반 저장소 (http://localhost:8090) — 반 코드 TEST-CLASS / 설치 열쇠 TEST-TEACHER (교사 앱에서 이걸로 첫 관리자 계정을 만들어요)
npm test           # 주제·기획서·프롬프트·저장·월드 배치 + Code.gs(가짜 Apps Script 위에서) 시험
npm run e2e        # 진짜 브라우저로 학생→교사→월드 전체 흐름 (Playwright + Chromium)
npm run slides     # 발표 자료 다시 만들기 (pptxgenjs)
```
