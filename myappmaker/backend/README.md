# 우리 반 저장소 만들기 (구글 Apps Script · 약 15분)

학생 20명의 기획서와 앱을 **버튼 하나로** 모으고, 메타버스 앱 월드에 부스를 자동으로 여는 저장소입니다.
선생님의 구글 계정 안(구글 시트 + 구글 드라이브)에 저장되고, 따로 서버 비용이 들지 않습니다.

> 📄 그림으로 보는 안내서: [`docs/우리반_저장소_설치안내.docx`](../docs/우리반_저장소_설치안내.docx) (교사 앱 ⚙️ 연결 설정에서도 받을 수 있어요)
>
> 저장소가 있으면 **관리자(선생님) 계정**과 **학생 아이디**를 만들 수 있어요. 학생은 아이디로 로그인해서 어느 노트북에서든 자기 기획서·앱을 이어서 쓰고 입점 상태를 봐요.

> 저장소 없이도 운영할 수 있어요. 학생이 **제출 파일**을 내려받아 클래스룸 등에 올리면 교사 앱에서 「📁 제출 파일 넣기」로 모읍니다.

## 1. 시트와 스크립트 만들기

1. [구글 시트](https://sheets.new)를 새로 만들고 이름을 `MY APP MAKER 우리 반`처럼 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 원래 들어 있는 코드를 모두 지우고, 이 폴더의 [`Code.gs`](Code.gs) 내용을 통째로 붙여 넣습니다.
4. 맨 위 두 줄을 바꿉니다 (영문·숫자, 서로 다르게).

   ```js
   var CLASS_CODE = 'DREAM-5-2';           // 반 코드: 학생·메타버스가 씀 (알려 줘도 됨)
   var TEACHER_KEY = 'my-secret-7391';     // 설치 열쇠: 선생님만 (첫 관리자 계정 만들기·비밀번호 잊었을 때)
   ```
5. 💾 저장합니다.

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**.
2. 톱니바퀴(유형 선택) → **웹 앱**.
3. 설정
   - 다음 사용자 인증 정보로 실행: **나(선생님 계정)**
   - 액세스 권한이 있는 사용자: **모든 사용자**
     (학생은 구글 로그인을 하지 않으므로 꼭 「모든 사용자」여야 합니다. 대신 반 코드·학생 아이디·관리자 비밀번호로 지킵니다.)
4. **배포** → 권한 검토에서 선생님 계정을 고르고 허용합니다.
   ("확인되지 않은 앱" 화면이 나오면 「고급 → (안전하지 않음)으로 이동」 — 선생님이 직접 만든 스크립트라서 나오는 안내입니다.)
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 3. 앱에 연결하기

- **교사 앱** → ⚙️ 연결 설정에 URL·반 코드를 넣고 「저장하고 연결 시험」 → ✅ 연결 성공
- 같은 화면의 **학생에게 나눠 줄 주소**를 복사해 클래스룸 등에 올립니다. 이 주소로 열면 학생 앱이 자동으로 연결됩니다.
- (선택) 사이트를 직접 올렸다면 `config.js`에 URL과 반 코드를 적어 두면 주소에 아무것도 붙이지 않아도 연결됩니다. **설치 열쇠는 절대 `config.js`에 쓰지 마세요.**

## 4. 관리자 계정 · 학생 계정 만들기

1. ⚙️ 연결 설정 아래 「👤 관리자 로그인」 → **처음 쓰나요?** 를 펼쳐 **설치 열쇠(TEACHER_KEY)** + 새 관리자 아이디 + 비밀번호(6자 이상) → ✨ 관리자 계정 만들기.
   다음부터는 아이디·비밀번호로 로그인합니다. 로그인한 관리자는 다른 관리자를 추가하고 비밀번호를 바꿀 수 있어요.
   관리자 비밀번호를 잊으면 같은 곳에서 설치 열쇠로 같은 아이디를 다시 만들면 비밀번호가 바뀝니다.
2. **👥 학생 계정** 탭 → 몇 명인지 넣고 ✨ 만들기 → 아이디(01, 02 …)와 비밀번호(숫자 4자리)가 만들어집니다.
   **🖨️ 로그인 카드 인쇄**로 오려서 나눠 주세요. 학생 이름은 아이디에 쓰지 마세요(번호만).
3. 학생은 카드의 아이디·비밀번호로 로그인합니다. 쓰는 내용은 저장소에 자동 저장되고, 다른 노트북에서 같은 아이디로 들어오면 이어집니다.
   비밀번호를 잊으면 👥 학생 계정 → 🔑 새 비밀번호. 10번 틀리면 그 아이디는 5분 동안 잠깁니다.

## 코드를 고친 뒤에는

새 `Code.gs`로 바꿀 때는 맨 위 **CLASS_CODE·TEACHER_KEY 두 줄을 원래 값으로 다시 적고** 저장한 뒤,
**배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 해야 반영됩니다 (URL은 그대로). 「새 배포」를 하면 주소가 바뀌니 주의하세요.

## 저장되는 것

| 위치 | 내용 |
|---|---|
| 시트 `제출` | 학생별 한 줄: 별명·앱 이름·주제·상태·피드백·부스 번호·좋아요·기획서(JSON) |
| 시트 `학생계정` | 학생 아이디·비밀번호(4자리)·마지막 로그인·작업 저장 시각 |
| 드라이브 `MY APP MAKER 학생 앱` 폴더 | 학생 앱 HTML 파일, 학생별 작업 저장 파일(`draft_아이디`), 월드 그림 |
| 스크립트 속성 | 앱 월드 설정, 관리자 계정(비밀번호는 암호화된 값만), 출입증 서명 열쇠 |

- 학생이 다시 제출하면 같은 줄이 최신 내용으로 바뀌고, 상태는 「확인 대기」로 돌아갑니다.
- 메타버스에는 **입점 승인**한 앱만 보입니다.
- 수업이 끝나면 시트를 보관하거나 삭제해 주세요. 별명 사용을 권장합니다.

## 지켜 주는 것과 한계

- 학생·메타버스는 **반 코드**가 있어야 읽고 쓸 수 있고, 목록 전체 보기·승인·삭제·계정 관리는 **관리자 로그인**(또는 설치 열쇠)이 있어야 합니다.
- 학생 작업 불러오기·저장은 **그 학생의 아이디로 로그인**해야만 됩니다. 로그인은 12시간 유지되고, 비밀번호를 새로 만들거나 계정을 지우면 예전 로그인은 바로 풀립니다.
- 학생 비밀번호(4자리)는 선생님이 다시 알려 줄 수 있도록 선생님 시트에 그대로 보관합니다. 시트는 선생님만 열 수 있게 두세요.
- 반 코드는 비밀번호가 아니라 "우리 반 표시"입니다. 학생 주소가 밖으로 퍼지면 다른 사람도 앱 월드를 볼 수 있으니, 공유 범위를 반 안으로 지켜 주세요.
- Apps Script 무료 사용량 안에서 한 반(20명) 수업에는 충분합니다. 동시에 많이 누르면 몇 초 늦어질 수 있습니다.
