선생님이 주신 카드의 아이디와 비밀번호(숫자 4자리)를 넣어요.

로그인하면 내가 쓴 기획서와 앱이 우리 반 저장소에 저장돼서, 다른 노트북에서도 같은 아이디로 이어서 할 수 있어요. 비밀번호를 잊으면 선생님께 말해요. 다 쓰면 꼭 「나가기」를 눌러요.

나만의 게임 앱을 만들어
메타버스 앱 월드에 열어요!

AI가 대신 만들어 주는 게 아니에요. 게임의 목표와 규칙, 캐릭터, 화면은 내가 정해요. AI는 내 기획서대로 코드를 짜 주는 도우미예요.

  1. 🎯주제 추천받기하고 싶은 걸 말하면 추천
  2. 📝기획서 쓰기목표·규칙·캐릭터
  3. 🤖프롬프트 받기AI에게 줄 설명서
  4. 🛠️앱 만들고 시험고쳐 달라고 하기
  5. 🏪메타버스 입점친구들이 놀러 와요

💾 저장은 이렇게 돼요

🔒 진짜 이름·학교·반·전화번호·주소는 어디에도 쓰지 않아요. 개발자 이름은 별명으로 써요.

1. 어떤 게임을 만들고 싶나요?

🔒 이미 있는 게임을 그대로 따라 한 것, 무섭거나(귀신·괴물·좀비) 다치게 하는 것, 놀리는 말·정치·인터넷 예절에 어긋나는 것, 배움이 없는 주제는 추천하지 않아요. 모든 추천에는 📚 배움 요소가 들어 있어요.

✏️ 추천에 없는 주제를 직접 쓸래요

내가 생각한 주제로 만들 수 있어요. 대신 이미 있는 게임·우리 반 친구 앱과 같은 것, 다치게 하거나 무서운 것(귀신·괴물·좀비 등), 놀리거나 미워하는 말, 정치·이념, 해킹·몰래 찍기·악플처럼 인터넷 예절에 어긋나는 것은 쓸 수 없어요.

3. AI에게 줄 프롬프트

🤖 앱 제작 프롬프트

선생님이 알려 준 AI 도구에 그대로 붙여 넣어요. 내 기획서 내용이 모두 들어가 있어요.


      

      

        
🎨 이미지 만들기 프롬프트 (선택 · 시간이 남으면)

        
이미지 생성 AI(Gemini 등)에 하나씩 넣어 그림을 만들고, 그림 파일을 저장해요. 그다음 「4. 내 앱 → 🖼️ 내 그림 넣기」에서 올리면 게임에 들어가요. 그림이 없어도 앱은 이모지로 잘 돌아가요.

        

        

      

      

        
💡 AI와 함께 만드는 순서

        
    
          
  1. 앱 제작 프롬프트를 붙여 넣어요.
    2. 
          
  2. AI가 준 코드를 통째로 복사해서 「4. 내 앱」에 붙여 넣고 실행해 봐요.
    3. 
          
  3. 이상한 곳이 있으면 「4. 내 앱 → 🔧 내 앱 고치기」에서 한 가지씩 고쳐 달라고 부탁해요.
    4. 
          
  4. 잘 되면 메타버스에 입점 신청!
    5. 
        

      

      

    


    
    

      
4. 내 앱 넣고 시험하기

      

        

          
① AI가 준 코드 붙여 넣기

          
3단계에서 복사한 프롬프트를 AI에게 보내고, AI가 만들어 준 답(코드)을 여기에 붙여 넣어요. 답 전체를 붙여 넣어도 코드만 골라내요. 또는 .html 파일을 올려도 돼요.

          
          

            
            
            
            
          

          

            🔗 코드 대신 공유 링크로 낼래요
            
            
공유 링크는 메타버스에서 새 창으로 열릴 수 있어요. 가능하면 코드를 붙여 넣는 게 좋아요.

          

          

        

        

          
② 실행 화면

          
        

      

      

        
🖼️ 내 그림 넣기 (선택)

        
    
          
  1. 📋 프롬프트 복사 → 이미지 AI에 붙여 넣어 그림 만들기 (앱 월드 지도 그림도 같이 올리면 앱 월드와 똑같은 그림체로 나와요)
    2. 
          
  2. 마음에 드는 그림을 기기에 저장
    3. 
          
  3. 📷 그림 올리기를 눌러 저장한 그림 고르기 → 게임에 바로 들어가요
    4. 
        

        

        

        

        

      

      

        
③ 테스트 체크리스트

        

      

      

        
🔧 내 앱 고치기 (고쳐 줘 프롬프트)

        
💡 한 번에 한 가지만 고쳐요. 고치고 → 실행해 보고 → 또 고쳐요. 진짜 이름·학교·전화번호는 쓰지 않아요.

        

        
자주 고치는 것 (누르면 채워져요)

        

        
        
        
③ 그대로 둘 것 (바뀌면 안 되는 것을 골라요)

        

        

        

        

          AI에게 보낼 프롬프트 전체 보기
          

        

        

        
    
          
  1. 복사한 프롬프트를 앱을 만든 AI 대화창에 붙여 넣어요.
    2. 
          
  2. AI가 준 새 코드 전체를 위 「AI가 준 코드 붙여 넣기」 칸에 붙여 넣고 ▶ 실행해 보기 (내 그림은 그대로 남아요).
    3. 
          
  3. 잘 고쳐졌는지 직접 해 보고 아래에서 골라요.
    4.
