# 픽셀 마법사 연구소 ✦ 작은 픽셀에 마법을 걸어봐!

초등학생(1~6학년, 주 대상 2~4학년)을 위한 **창작형 코딩 교육 웹앱**입니다.
명령 블록으로 마법 펜을 움직여 픽셀 그림을 그리고, 그림을 이어 붙여 애니메이션을 만듭니다.

- 회원가입·서버·API 키 없이 브라우저만으로 동작합니다.
- 작품과 미션 기록은 그 컴퓨터 브라우저의 `localStorage`에 저장되어 새로고침해도 남아 있습니다.
- 정적 웹 호스팅(GitHub Pages, Netlify, 학교 웹서버, USB 등 어디든)에 `dist/` 폴더만 올리면 됩니다.

---

## 1. 바로 사용하기 (빌드된 파일)

`dist/` 폴더가 완성된 앱입니다.

- **웹 서버에 올리기**: `dist/` 안의 모든 파일을 그대로 업로드하면 됩니다. 하위 폴더 주소(예: `https://학교.kr/coding/pixel/`)에서도 동작합니다.
- **내 컴퓨터에서 바로 열기**: 보안 정책 때문에 `index.html`을 더블클릭하면 동작하지 않을 수 있습니다. 아래처럼 간단한 로컬 서버로 여세요.

```bash
npx vite preview --port 4173
```

또는 (파이썬이 있는 경우)

```bash
cd dist && python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173` 을 엽니다. (권장: Chrome / Edge 최신 버전)

## 2. 개발 환경에서 실행하기

Node.js 18 이상이 필요합니다.

```bash
npm install
```

```bash
npm run dev
```

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 실행 (수정하면 바로 반영) |
| `npm run build` | 타입 검사 후 `dist/`에 배포용 빌드 생성 |
| `npm run preview` | 빌드 결과를 로컬 서버로 확인 |
| `npm test` | 실행 엔진·미션 정답·블록 편집·GIF 단위 테스트 (Vitest) |
| `npm run e2e` | 실제 브라우저로 전체 기능 확인 (아래 참고) |
| `npm run zip` | `pixel-magic-lab.zip` 전체 프로젝트 압축 |

### 브라우저 자동 테스트 (선택)

```bash
npm i -D playwright && npx playwright install chromium
```

```bash
npm run build && npx vite preview --port 4173
```

다른 터미널에서

```bash
npm run e2e
```

> 리눅스 서버에서 한글 다운로드 파일 이름까지 확인하려면 `LANG=C.UTF-8` 로캘에서 실행하세요.

## 3. 세 가지 모드

### 모드 A — 마법 따라 그리기 (미션 12개)

목표 그림과 똑같이 그리는 학습 모드입니다. 왼쪽 블록 상자 → 가운데 도화지 → 오른쪽 미션 안내 순서로 구성됩니다.

| # | 미션 | 난이도 | 핵심 학습 |
|---|---|---|---|
| 1 | 첫 번째 마법 점 | 쉬움 | 색칠 명령 |
| 2 | 반짝이는 가로줄 | 쉬움 | 이동과 순서(순차 실행) |
| 3 | 알록달록 계단 | 쉬움 | 네 방향 · 색 바꾸기 |
| 4 | 네모난 마법 창문 | 쉬움 | 이동과 패턴 |
| 5 | 하트 만들기 | 보통 | 좌표와 색칠 |
| 6 | 반복되는 무지개 | 보통 | 반복문 |
| 7 | 마법사의 꽃 | 보통 | 반복과 패턴 |
| 8 | 귀여운 버섯 | 보통 | 색 바꾸기와 반복 |
| 9 | 별빛 장식 | 도전 | 중첩 반복 · 효율 |
| 10 | 마법사의 시험 | 도전 | 종합 |
| 11 | 고장 난 마법 고치기 | 도전 | 디버깅 (고장 난 코드로 시작) |
| 12 | 체크무늬 마법 융단 | 도전 | 중첩 반복 알고리즘 |

- 결과 그림의 모든 칸 색이 목표와 같으면 성공 (코드 순서가 달라도 결과가 같으면 정답).
- 성공: 별 2개 + 기준 블록 수 이하이면 **효율 보너스 별** 1개, 완료 도장, 다음 미션 열림.
- 다른 칸이 있으면 ✕ 표시(색이 아닌 점선 테두리 + 엑스 모양)로 알려 주고, 힌트·목표 겹쳐 보기·다시 도전을 제안합니다.
- 힌트는 미션마다 3단계로 조금씩 열립니다. 작성 중인 코드는 미션별로 자동 저장됩니다.

### 모드 B — 자유 픽셀 공방

- 8×8 / 10×10 / 16×16 도화지, 14색 팔레트.
- 기본 제작 방식은 **명령 블록**입니다. 보조 도구로 붓·지우개(손그림 밑바탕)를 쓸 수 있고,
  **「손그림 → 코드」** 버튼으로 손그림을 반복 블록이 들어간 마법 주문으로 바꿔 볼 수 있습니다.
- 되돌리기 / 다시 하기 (Ctrl+Z / Ctrl+Y), 작품 이름, 저장·불러오기·삭제(확인 창), PNG 다운로드.
- 저장 정보: 작품 이름, 완성 픽셀, 손그림, 명령 블록, 캔버스 크기, 펜 색, 수정 날짜.

### 모드 C — 움직이는 픽셀 극장

- 프레임 추가·복사·삭제·순서 변경(최대 24장), 이전 프레임 비추기(어니언 스킨).
- **프레임마다 명령 블록과 손그림을 따로 보관**합니다.
- 재생/정지, 속도(느리게·보통·빠르게), 반복 재생, 크게 보기(발표용).
- 예시 템플릿 5종: 눈 깜빡이는 고양이, 통통 뛰는 토끼, 반짝이는 별, 피어나는 꽃, 걷는 공룡.
- 내보내기: **애니메이션 GIF**(자체 인코더, 무한 반복) 및 **프레임 스프라이트 시트 PNG**.

## 4. 명령 블록과 실행 규칙

| 블록 | 설명 |
|---|---|
| 위로/아래로/왼쪽으로/오른쪽으로 1칸 | 펜 위치만 옮깁니다 |
| 칠하기 | 지금 칸을 펜 색으로 칠합니다 |
| 지우기 | 지금 칸을 비웁니다 |
| 색 고르기 | 펜 색을 바꿉니다 (칠하지는 않음) |
| 좌표로 이동 (x, y) | 그 칸으로 순간이동 (미션 5부터) |
| N번 반복하기 | 안에 넣은 블록을 N번 실행. 반복 안에 반복(중첩)도 가능 |

- 좌표는 왼쪽 위가 (0, 0). 실행할 때마다 도화지를 초기화하고, 펜은 (0, 0)에서 출발하며 저절로 칠하지 않습니다.
- 도화지 밖으로 나가려 하면 그 블록에서 멈추고 빨간 ! 표시와 함께 "앗! 마법 펜이 도화지 밖으로 나가려고 해요!" 라고 안내합니다.
- 안전 제한: 반복 횟수 최대 30번, 전체 실행 최대 4,000단계 (초과 시 친절한 안내 후 정지).
- 실행 도구: 실행 · 멈춤/계속 · 한 단계 · 처음부터 · 지우기(결과 초기화) · 속도 4단계 (미션 화면에서는 Ctrl+Enter 로도 실행).
- 실행 중인 블록 강조(▶ 화살표 + 테두리), 반복 블록에 `2/5` 같은 현재 반복 번째 표시, 펜 위치는 굵은 테두리 + 점선 + 별 배지로 색과 상관없이 보입니다.

### 블록 편집 방법 (저학년도 쉽게)

- **클릭**: 블록 상자의 블록을 누르면 「✦ 새 블록은 여기에」 위치에 들어갑니다. 반복 블록을 누르면 그 안에 들어갑니다.
- **드래그**: 마우스로 블록을 끌어 순서를 바꾸거나 반복 안팎으로 옮깁니다. 터치 화면에서는 블록을 0.3초 꾹 누른 뒤 끌어요(그냥 쓸면 목록이 스크롤됩니다). 아래 휴지통 영역에 놓으면 지워집니다.
- **선택한 블록의 버튼**: ↑ ↓ (한 칸 이동, 반복 밖으로 꺼내기) · 복사 · 지우기. 키보드 Delete 키도 지원.
- 반복 횟수·좌표는 − / + 버튼 또는 숫자 입력, 색은 색 버튼을 눌러 고릅니다.

## 5. 선생님 메뉴 (상단 모자 아이콘)

- 모든 미션 열기 (수업 진도에 맞게 바로 선택)
- 「정답 코드 보기」 버튼 표시 → 미션 화면에서 예시 정답을 보고 작업 공간에 불러오기
- 미션별 결과(별, 사용한 블록 수) 표
- 전체 화면, 미션 기록 초기화(확인 창)
- 상단 ? 아이콘: 학생용 사용 방법 안내 (처음 접속 시 자동 표시)
- 상단 스피커 아이콘: 효과음 음소거 (설정 저장됨)

> 기록은 컴퓨터(브라우저)별로 저장됩니다. 공용 컴퓨터에서는 학생 작품을 PNG/GIF로 내려받아 모으는 것을 권장합니다.

## 6. 화면 크기

- PC 1366×768 (브라우저 창 안쪽 약 1366×657 포함) 및 1280×720(안쪽 약 1280×610)에서 **페이지 스크롤 없이** 세 모드의 주요 기능과 실행 버튼이 모두 보이도록 자동 테스트로 확인했습니다. 블록이 많아지면 '내 마법 주문' 칸 안에서만 스크롤됩니다.

## 7. 프로젝트 구조

```
pixel-magic-lab/
├─ index.html, vite.config.ts, tsconfig.json, package.json
├─ public/favicon.svg
├─ src/
│  ├─ engine/         ← 실행 엔진 (UI와 분리)
│  │  ├─ types.ts     블록·단계(Step)·오류 데이터 구조
│  │  ├─ engine.ts    프로그램 → 단계별 실행 기록(현재 블록, 좌표, 색, 픽셀 변경, 반복 번째, 오류)
│  │  ├─ tree.ts      블록 트리 편집(삽입·이동·삭제·복사), 손그림→코드 변환
│  │  └─ engine.test.ts  단위 테스트 (12개 미션 정답 실행 검증 포함)
│  ├─ data/           미션 12개, 팔레트, 애니메이션 템플릿
│  ├─ lib/            useRunner(단계 재생기), 저장소, 효과음, PNG/GIF 내보내기
│  ├─ components/     블록 편집기, SVG 픽셀 도화지, 아이콘·마스코트(SVG), 공용 UI
│  ├─ modes/          MissionMode / StudioMode / TheaterMode
│  └─ styles.css      디자인 시스템 (크림·라벤더·민트·핑크·버터)
├─ tests-e2e/e2e.mjs  Playwright 브라우저 테스트 (52개 항목)
├─ scripts/make-zip.mjs
└─ dist/              정적 호스팅용 빌드 결과
```

그래픽은 모두 코드(CSS·SVG)로 그렸습니다. 외부 이미지 파일이나 이모지를 쓰지 않으며, 글꼴은 오픈 폰트 **주아체(Jua, SIL OFL)** 를 `@fontsource/jua`로 함께 묶어 인터넷 없이도 표시됩니다.

## 8. 검증 결과

- `npm test`: 33개 단위 테스트 통과 — 기본 명령, 반복·중첩 반복, 도화지 밖 이동, 반복 횟수 초과·무한 실행 방지, **12개 미션 정답 코드 실행 → 목표와 일치**, 디버깅 미션 시작 코드가 실제로 고장 나 있는지, 블록 편집, 손그림→코드 변환, GIF 인코딩.
- `npm run e2e`: 52개 브라우저 테스트 통과 — 클릭/드래그 편집, 실행·멈춤·한 단계·계속, 오류·틀린 칸 표시, 12개 미션을 화면에서 실제로 실행해 성공 판정, 새로고침 후 기록 유지, 공방 저장·불러오기·삭제·PNG, 극장 프레임 편집·어니언 스킨·템플릿·재생·GIF/스프라이트 내보내기·저장, 4가지 화면 크기에서 스크롤 없음.
- 생성된 GIF는 별도 디코더(Pillow)로 열어 프레임 수·반복·색상을 확인했습니다.

## 9. 알려진 한계

- 저장소가 브라우저(localStorage, 약 5MB)라서 다른 컴퓨터와 자동으로 공유되지 않습니다.
- 일부 브라우저에서 효과음은 화면을 한 번 누른 뒤부터 납니다(브라우저 자동 재생 정책).
- 안드로이드 태블릿 등 터치 환경은 레이아웃·드래그를 고려해 만들었지만, 실제 기기 테스트는 하지 않았습니다(자동 테스트는 데스크톱 Chromium 기준).
