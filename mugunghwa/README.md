# 무궁화 꽃이 피었습니다 🌺

노트북·태블릿 카메라가 **술래**가 되는 아이들 몸놀이 웹앱이에요.

- 술래가 "무궁화 꽃이 피었습니다~" 하는 동안 **팔을 위아래로 흔든 횟수만큼** 내 캐릭터가 술래 쪽으로 가요. (한 번 흔들 때마다 2.5칸, 많이 흔들수록 많이 가요)
- "**얼음!**" 하고 술래가 돌아봤을 때 움직이면 걸려서 **뒤로** 가요.
- 결승선에 먼저 도착하면 이겨요.

## 설정

| 설정 | 고를 수 있는 것 |
|---|---|
| 누구랑 | 혼자 / 둘이서 (화면 왼쪽 = 1P 🐰, 오른쪽 = 2P 🐻) |
| 술래 눈치 | 너그러움 · 보통 · 매의 눈 |
| 술래 목소리 | 켜기 · 끄기 |

| 눈치 | "얼음!" 뒤 봐주는 시간 | 걸리는 움직임 | 걸리면 뒤로 |
|---|---|---|---|
| 너그러움 | 0.9초 | 크게 움직일 때만 | 10칸 |
| 보통 | 0.6초 | 보통 | 15칸 |
| 매의 눈 | 0.35초 | 작은 움직임도 | 20칸 |

(길 전체는 100칸이에요. 팔을 40번 흔들면 도착해요. 카메라 화면 아래 👋 숫자가 흔든 횟수예요.)

## 개인정보 지키기 🔒

- 몸 인식은 **이 기기 안에서만** 해요. 카메라 장면을 아주 작게(80×60) 줄여 앞뒤 장면이 얼마나 달라졌는지만 세고, 장면은 곧바로 다음 장면으로 덮어써요.
- 팔 흔들기는 화면 위쪽(다리 빼고)에서 움직이는 곳의 높이가 위↔아래로 바뀌는 횟수로 세요.
- 영상·사진을 **저장하지도, 어디에 보내지도 않아요.** 인공지능 모델을 내려받지도 않아요.
- `index.html`의 보안 규칙(Content-Security-Policy)이 이 앱의 파일 말고 다른 곳으로는 연결 자체를 막아요.
- "그만하기"나 "처음으로"를 누르면 카메라가 바로 꺼져요.
- 술래 목소리는 브라우저의 음성 합성을 쓰고, 기기 안의 한국어 목소리가 있으면 그것을 먼저 골라요.

## 홈 화면에 설치

앱 설치 정보(`manifest.webmanifest`)와 오프라인 도우미(`sw.js`)가 들어 있어서, 한 번 열고 나면 인터넷 없이도 놀 수 있어요.

- **안드로이드/크롬·엣지**: 첫 화면의 "📲 홈 화면에 앱 설치하기" 또는 브라우저 메뉴 → "앱 설치"
- **아이패드/아이폰(사파리)**: 공유 버튼 → "홈 화면에 추가"

카메라는 **https 주소**(또는 내 컴퓨터의 `localhost`)에서만 켜져요. GitHub Pages 같은 곳에 `mugunghwa/` 폴더를 그대로 올리면 돼요.

## 내 컴퓨터에서 열어 보기

```bash
cd mugunghwa
python3 -m http.server 8080
```

브라우저에서 http://localhost:8080 을 열어요.

## 시험

```bash
npm test        # 놀이 규칙·움직임 재기 (Node 18+)
npm run e2e     # 진짜 브라우저에 가짜 카메라 영상을 넣어 끝까지 놀아 보기 (Playwright + Chromium 필요)
```

## 파일

```
mugunghwa/
├── index.html            화면
├── style.css             꾸미기
├── manifest.webmanifest  홈 화면 앱 정보
├── sw.js                 오프라인 도우미
├── js/
│   ├── app.js            화면 전환·카메라·놀이 진행
│   ├── game.js           놀이 규칙 (카메라와 상관없는 순수 로직)
│   ├── motion.js         움직임 재기 (장면 비교)
│   ├── scene.js          놀이 마당 그림
│   └── sound.js          술래 목소리·효과음
├── icons/                앱 아이콘 (tools/make-icons.py 로 만듦)
└── tests/                시험
```
