# 블록 로봇 교실 미로 (주간 게임 3주차)

화살표 명령 블록(↑ ↓ ← →)을 **차례대로** 놓아 블록 로봇이 교실 미로(책상·사물함 사이)를 지나
별을 모두 모으고 깃발에 도착하게 하는 길 찾기 게임이에요. 대상 초2~4, 한 판 3~5분.

- 학습 목표: 순서대로 움직이는 명령(순차)을 짜서 목적지에 갈 수 있다.
- 모드 1개, **8단계**(뒤로 갈수록 길이 길어지고 별·장애물이 늘어요). 반복 블록은 없어요(다음 문제 팩).
- 실패하면 틀린 블록이 **빨간색**으로 강조되고, `한 칸씩 보기` 로 블록을 하나씩 실행하며 어디서 틀렸는지 볼 수 있어요.
- 성공하면 별점(가장 짧은 길이면 ★★★). 깬 단계는 이 기기에만 기억해요(저장이 막혀 있어도 게임은 그대로 돼요).
- 설치·로그인·인터넷 연결(외부 그림·글꼴) 없이 동작하고, 아무 정보도 모으지 않아요.
- 키보드: 화살표 키로 블록 놓기, `Backspace` 로 하나 빼기, `Tab`/`Enter` 로 버튼 누르기.

## 실행

```bash
cd games/robot-maze
npm start        # http://localhost:8080 에서 열기 (python3 필요)
npm test         # 게임 규칙·단계표 테스트 (node 18 이상, 따로 설치할 것 없음)
```

## 단계표(JSON) 바꾸기

단계는 `data/levels.json` 에 있어요. 이 파일만 고치면 단계가 바뀌어요.

```json
{
  "title": "블록 로봇 교실 미로",
  "levels": [
    { "name": "첫 걸음", "tip": "오른쪽으로 쭉!", "maxBlocks": 8, "map": ["S.*.G"] },
    { "name": "책상 돌아가기", "map": ["S..", "DD.", "G*."] }
  ]
}
```

지도(`map`)는 한 줄이 교실의 한 줄이에요. 글자 하나가 한 칸이에요.

| 글자 | 뜻 |
| --- | --- |
| `S` | 로봇 출발 칸 (꼭 1개) |
| `G` | 도착 깃발 (꼭 1개) |
| `*` | 별 (0~5개, 모두 모아야 성공) |
| `D` | 책상 (지나갈 수 없음) |
| `L` | 사물함 (지나갈 수 없음) |
| `.` | 빈 바닥 |

| 칸 | 꼭 필요? | 뜻 |
| --- | --- | --- |
| `title` | 아니요 | 화면 맨 위 제목 (40자까지) |
| `levels` | 예 | 단계 목록. 1~20개 |
| `map` | 예 | 지도. **7줄 × 7칸까지**, 모든 줄 길이가 같아야 해요 |
| `name` | 아니요 | 단계 이름 (40자까지) |
| `tip` | 아니요 | 지도 위에 나오는 도움말 (40자까지) |
| `maxBlocks` | 아니요 | 놓을 수 있는 블록 수 (1~24, 없으면 16) |

지켜야 할 것

- 별을 모두 모아 깃발에 갈 수 있는 길이 꼭 있어야 하고, 그 가장 짧은 길이 `maxBlocks` 안에 들어가야 해요.
- 문제표에 잘못된 곳이 있으면 시작 화면에 노란 안내가 뜨고 기본 단계로 시작해요.
- 고친 뒤 `npm test` 를 돌리면 `data/` 안의 모든 JSON 이 올바른지, 단계마다 풀 수 있는지 검사해요.

### 다른 단계표 쓰기 (`?set=`)

`data/` 폴더에 새 JSON 파일(예: `data/class3.json`)을 넣고 주소 끝에 `?set=class3` 을 붙여요.
파일 이름은 영어 소문자·숫자·`-`·`_` 만 써 주세요.

## 수업 활용 (3~5분)

- **코딩 수업 도입**: 1~2단계를 화면에 띄우고 반 전체가 "오른쪽! 아래!"를 외치며 블록을 함께 놓기 → 실행.
  일부러 한 블록을 틀리게 놓고 `한 칸씩 보기` 로 빨간 블록을 찾아보기.
- **레고 로봇 수업 전 몸풀기**: 짝끼리 3~5단계에 도전. 한 명은 블록을 놓고, 한 명은 손가락으로 길을 따라가며 확인.
