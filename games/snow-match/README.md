# 눈송이 짝 맞추기 (주간 게임 1호)

겨울 낱말 ↔ 그림 카드와 코딩 개념(순차·반복) 카드를 두 장씩 뒤집어 짝을 찾는 메모리 게임이에요.
겨울 애니메이션 수업의 **도입·정리 3~5분 게임**으로 쓰기 좋아요.

- 난이도: **쉬움 6쌍(카드 12장)** / **보통 8쌍(카드 16장)**
- 시도 횟수·시간 표시, `다시 하기` 버튼, 끝나면 한 줄 정리
- 설치·로그인·인터넷 연결(외부 그림·글꼴) 없이 동작하고, 아무 정보도 모으지 않아요.
- 키보드로도 할 수 있어요: `Tab` 으로 카드 이동, `Enter`/`Space` 로 뒤집기

## 실행

```bash
cd games/snow-match
npm start        # http://localhost:8080 에서 열기 (python3 필요)
npm test         # 게임 규칙 테스트 (node 18 이상, 따로 설치할 것 없음)
```

> 파일을 더블클릭해서 열면 브라우저가 문제표(JSON)를 못 읽어서 **기본 카드**로 시작해요.
> 선생님이 고친 문제표를 쓰려면 위처럼 서버로 열거나, 배포된 주소로 열어 주세요.

## 문제표(JSON) 바꾸기

카드는 `data/cards.json` 에 있어요. 이 파일만 고치면 카드가 바뀌어요.

```json
{
  "title": "눈송이 짝 맞추기",
  "pairs": [
    { "a": "눈송이", "b": "❄️", "bLabel": "눈송이 그림", "type": "겨울" },
    { "a": "순차", "b": "차례대로 한 줄씩 실행", "type": "코딩" }
  ]
}
```

| 칸 | 꼭 필요? | 뜻 |
| --- | --- | --- |
| `title` | 아니요 | 화면 맨 위 제목 (40자까지) |
| `pairs` | 예 | 짝 목록. **2개 이상, 30개까지**. 보통(8쌍)을 하려면 8개 이상 |
| `a`, `b` | 예 | 서로 짝인 두 카드의 글자(또는 이모지). 한 장에 **30자까지**, 짧을수록 보기 좋아요(10자 안팎) |
| `aLabel`, `bLabel` | 아니요 | 화면 읽기 프로그램이 읽어 줄 이름. 이모지 카드에는 `"눈송이 그림"` 처럼 적어 주세요. 없으면 카드 글자를 그대로 읽어요 |
| `type` | 아니요 | 카드 종류(예: `겨울`, `코딩`). 종류가 여러 개면 쉬움(6쌍)에서도 **종류마다 적어도 한 쌍**은 꼭 나와요 |

지켜야 할 것

- 모든 카드 글자는 서로 달라야 해요(같은 글자가 두 번 나오면 짝이 헷갈려요).
- 짝이 8개보다 많으면 판마다 그중에서 골라 섞어 내요. 적으면 있는 만큼만 나와요.
- 문제표에 잘못된 곳이 있으면 시작 화면에 노란 안내가 뜨고 기본 카드로 시작해요.
- 고친 뒤 `npm test` 를 돌리면 `data/` 안의 모든 JSON 이 올바른지 검사해요.

### 다른 문제표 쓰기 (`?set=`)

`data/` 폴더에 새 JSON 파일(예: `data/coding.json`)을 넣고 주소 끝에 `?set=파일이름` 을 붙여요.

- 기본: `.../games/snow-match/`
- 코딩 낱말 모음: `.../games/snow-match/?set=coding`

파일 이름은 영어 소문자·숫자·`-`·`_` 만 써 주세요.

## 수업 활용 (3~5분)

- **도입**: 쉬움(6쌍)으로 반 전체가 화면을 보며 "몇 번째 카드?"를 외쳐 함께 맞히기.
- **정리**: 보통(8쌍)으로 모둠별 도전. 끝 화면의 한 줄 정리(시도 횟수·시간)로 기록 비교.
- 코딩 카드(순차·반복)가 나오면 오늘 만든 겨울 애니메이션 블록과 연결해 한 마디씩 설명하기.

## 파일

- `index.html`, `style.css` — 화면
- `js/game.js` — 게임 규칙(섞기·짝 확인·끝 판정·문제표 검사). 브라우저와 node 테스트가 함께 써요
- `js/app.js` — 화면 연결
- `data/*.json` — 문제표
- `tests/game.test.js` — `npm test`
