# 🚦 순발력 신호등

초록 불엔 탭, 빨간 불엔 멈춤! 20초가 지나면 낱말이 나와서 고른 종류(예: 과일)일 때만 탭하는 60초 순발력·주의력 게임이에요. 초등 1~4학년 수업 시작 3분 집중 놀이용.

- 주소: https://laonhyeum-collab.github.io/thedream/games/signal-tap/
- 단계: 1단계(0~20초) 색 신호 → 2단계(20~40초) 낱말 고르기 → 3단계(40~60초) 더 빨리
- 점수: 맞게 탭 +1, 0.6초 안에 탭 ⚡+2, 잘 참음 +1, 참아야 할 때 탭 -1 (0점 아래로 안 내려가요)
- 저장·로그인·이름 입력 없음. 점수는 화면에만 보여요.
- 키보드: 스페이스 키로 탭

## 선생님: 낱말 바꾸기
`data/` 폴더에 낱말 파일(JSON)을 하나 더 넣고 주소 끝에 `?set=파일이름`을 붙여요.

```json
{ "title": "3학년 과학", "sets": [
  { "target": "곤충", "yes": ["개미", "나비", "벌", "잠자리"], "no": ["거미", "지렁이", "참새", "달팽이"] }
] }
```
- `target`: 탭할 종류 이름(12자까지) · `yes`: 탭할 낱말 · `no`: 참을 낱말 (각각 3개 이상)
- 파일에 문제가 있으면 첫 화면에 고칠 곳을 알려 주고, 열 수 없으면 기본 낱말을 써요.
