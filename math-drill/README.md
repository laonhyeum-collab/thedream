# 연산 문제은행 (Block & Bit)

학년 · 학기 · 단원 · 난이도(쉬움/보통/어려움) · 문제 수(10/15/20/30)를 고르면
**풀이 칸이 있는 A4 문제지**와 **정답지**를 함께 만들어요. 2022 개정 교육과정의 연산 중심 단원(초1~중3, 57개 단원)을 담았어요.

- 문제지 위쪽에 **날짜 · 이름** 칸, 학년·단원·난이도·문제 번호가 들어가요.
- 문제마다 **풀이 칸**(좁게/보통/넓게)과 답 칸이 있어요.
- 도형 넓이·부피, 분수 막대/원, 각도, 평행선, 수직선, 시계, 부채꼴, 직각삼각형 문제는 **그림(SVG)을 그려서** 내요.
- **인쇄하기 / PDF로 저장**: 정답지는 새 쪽에서 시작해요. `문제지 + 정답지`, `문제지만`, `정답지만` 중에 골라 인쇄할 수 있어요.
  PDF 파일은 인쇄 창의 대상(프린터)에서 **PDF로 저장**을 고르면 돼요.
- **생활 속 문장제**: 37개 단원에서 네 문제마다 한 문제는 교과서·문제집처럼 상황 속에서 계산하는 문장제예요(리본 잇기, 거스름돈, 버스 배차, 사다리 높이, 할인 가격 등). 단원마다 상황을 여러 개 두었어요(`js/words.js`).
- **같은 문제 반복 막기**: 숫자만 바꾼 같은 모양의 문제가 바로 이어지지 않게 하고, 최근 5문제 안에서 같은 모양은 2번까지만 나와요(계산 모양이 한 가지뿐인 계산 연습은 예외).
- **그림 더하기**: ㄱ자 도형 넓이, 점 배열(곱셈·나눗셈), 띠 그림(길이·뺄셈), 정다각형, 벽에 기댄 사다리 그림을 새로 넣었어요.
- **문제 번호(시드)**: 같은 단원·난이도에 같은 번호를 넣으면 똑같은 문제지가 다시 나와요. 주소(#u=…&s=…)를 공유해도 같은 문제지가 열려요.
- **화면에서 바로 풀기 (10문제)**: 태블릿·컴퓨터에서 한 문제씩 답을 쓰고 바로 맞음/틀림을 확인해요. 끝나면 점수와 함께 **틀린 문제 다시 풀기**를 할 수 있고, 다시 풀어도 틀린 문제는 그때 정답을 볼 수 있어요. 저장·로그인·이름 입력이 없어요. 주소(#…&m=solve)를 학생들에게 알려 주면 반 전체가 같은 10문제를 풀어요. 분수는 `3/4`, 대분수는 `1 2/5`, 순환소수는 `0.3(7)`, 근호는 `2루트6`, 거듭제곱은 `x^2`처럼 써요(채점 규칙은 `js/check.js`).
- 설치·로그인·인터넷 연결 없이 동작하고, 이름·날짜 등 아무 정보도 저장하지 않아요.
- 답은 정확한 값으로 만들어요: 분수는 기약분수(4학년 이하 같은 분모 분수·분수 읽기는 교과서처럼 약분하지 않아요), 초등 뺄셈은 음수가 나오지 않고, 나눗셈은 나누어떨어지거나 몫·나머지로 내요.

교과서(출판사)마다 단원 이름·순서가 조금 다를 수 있어요. 단원은 `js/units.js`, 문제 만드는 규칙은 `js/generators.js` 에 있어요.

## 실행 · 테스트

```bash
cd math-drill
npm start   # http://localhost:8080 (index.html 을 그냥 더블클릭해도 돼요)
npm test    # 화면 풀기 채점(정답은 맞음·숫자 바꾼 답은 틀림)과 모든 단원 × 난이도 3 × 시드 4개 × 30문제(2만 개 이상)의 정답을 생성기와 따로 다시 계산해 확인
```
